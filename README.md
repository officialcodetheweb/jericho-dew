# JERICHO DEW — call site

The phone app for **Jericho Afasuo Prayer City** voice services. Members open the join link from the JERICHO DEW desktop app, sign in with the username and password their admin gave them, and join the call.

This site is updated automatically by the JERICHO DEW desktop app (Settings → Call site).

Preview without a voice server: add `?demo` to the address.
